See the layout before you need it.

Twelve macOS window positions: halves, quarters, thirds and two-thirds. Pick one and look at the shape. LumePane applies the same layouts to the real windows.

Left halfPreview only; no windows are moved.

What this is: a visual reference for common tiling positions. It does not resize real windows. LumePane's Window Layouts apply these positions through the macOS Accessibility API, with a drag-to-snap fallback; unsupported apps are reported instead of silently doing nothing.

LumePane has 12 window layouts, a floating Glow Orb, display control and smooth wheel scrolling. 14-day trial; no account.
