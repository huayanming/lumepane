6.0의 새로운 기능

디스플레이 패널은 실제 HDR/EDR 상태, 회전 각도, 현재 ICC 프로파일을 표시하며 지원되는 패널에서는 하드웨어 색온도(VCP 0x0C) 슬라이더를 제공합니다. 도구 패널에는 메모리 기반 클립보드 기록과 스크린샷 카드가 추가되었습니다. 오디오는 각 출력의 샘플 레이트, 마우스는 키 반복 설정과 트랙패드 읽기 전용 상태, 창은 다른 앱 가리기를 추가했습니다. 7.1.0에서는 Night Shift 읽기 전용 카드와 집중 모드 권한 설명을 추가했습니다.

메뉴 막대

메뉴 막대 아이콘을 클릭하면 메인 창을 열지 않고 조작판이 열립니다.

명령줄

바이너리에는 패널과 같은 컨트롤과 자가 테스트가 들어 있습니다. 스크립트에도, 앱 자체의 주장을 확인하는 데도 쓸 수 있습니다.

플래그하는 일
--list / --list-modes온라인 디스플레이와 모든 모드(macOS가 숨긴 HiDPI 모드 포함)를 나열합니다.
--set-brightness / --offset-brightness / --set-temperature소프트웨어 디밍을 설정하고, 상대적으로 조정하고, 색온도(2700–9000 K)를 설정합니다.
--preset / --set-resolution / --reset장면 프리셋을 적용하고, 해상도를 전환하고(HiDPI 우선), 캘리브레이션을 ColorSync로 돌려줍니다.
--dump-gamma현재 감마 테이블의 중간값을 출력합니다. 읽기 전용입니다.
--login-item / --request-accessibility로그인 시 실행을 읽거나 설정합니다. 손쉬운 사용 권한을 요청합니다.
--scroll-report / --scroll-selftest실시간 스크롤 진단. 보간 알고리즘과 총량 보존을 검증합니다.
--license-selftest / --cli-selftest라이선스 상태 기계와 축소 경계. 인자 퍼징, 마스킹, 오픈소스 고지.
--switch-probe / --switch-selftest읽기 전용 스위치 가용성과 상태. 읽기→전환→읽기 자가 테스트.
--probe / --full / --language / --help진단, 전체 출력, 인터페이스 언어, 도움말.

의도적으로 하지 않는 것

  • 다크 모드, 방해 금지 모드, Night Shift, True Tone, 데스크톱 숨기기: 시스템 비공개 인터페이스가 필요하고 공개 API로는 깔끔하게 할 수 없습니다.
  • Xcode 캐시 원클릭 삭제, 메뉴 막대에서 해상도 전환: 전자는 실제로 데이터를 지우고, 후자는 화면이 꺼질 수 있습니다.
  • 키보드 잠금: 키보드가 반응하지 않게 남을 수 있어 원클릭 동작으로 두지 않았습니다.
  • 텔레메트리도, 분석도, 계정 시스템도 없습니다.

개인정보 경계

검증은 완전히 오프라인입니다. 긴 LP- 코드는 앱 안에 들어 있는 공개 키로 Ed25519 검증을 합니다. 앱이 네트워크를 쓰는 곳은 활성화할 때뿐입니다 — 짧은 코드 교환과 기기 1회 등록이며, 대상은 Neeson & Sea 라이선스 서비스입니다. 긴 LP- 코드를 5대의 Mac으로 제한할 수 있는 이유가 이것입니다. 이 등록이 보내는 것은 보드 식별자(IOPlatformUUID)와 모델 식별자에서 로컬로 계산한 되돌릴 수 없는 SHA-256 다이제스트뿐입니다. 일련번호, 평문 모델 문자열, MAC 주소, 디스플레이 EDID, 사용자 이름, 계정은 보내지 않습니다. 이후 실행은 모두 로컬에서 검증되며, 업데이트 확인은 Sparkle(MIT)이 하고 기본적으로 꺼져 있습니다. 내보낸 진단 리포트는 앱을 떠나기 전에 일련번호, 라이선스 코드, 절대 경로, 사용자 이름을 지웁니다.

이 페이지의 주장은 확인할 수 있게 적었습니다. 위의 자가 테스트 명령은 바이너리의 일부이고, 투명성 페이지에 각 명령이 무엇을 검증하는지 나와 있습니다.
