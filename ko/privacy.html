개인정보 처리방침

최종 업데이트: 2026년 10월 18일

한 문장으로: LumePane은 앱 내에서 필수 텔레메트리도 계측도 하지 않습니다. 분석 SDK가 없고 사용 방식을 보고하지도 않습니다. 라이선스 서비스에는 집계 카운터가 몇 개 있습니다(다음 문단) — 여기서 "통계"라 부를 수 있는 것은 그것뿐입니다.

선택적 익명 사용 통계(기본 꺼짐). ‘정보’에서 ‘익명 사용 통계’를 켠 경우에만 하루 최대 한 번 무작위 설치 ID, 버전, 체험/라이선스 상태를 보냅니다. 서비스는 ID의 SHA-256 해시만 저장하며 IP, 계정, 디스플레이, 사용 내용은 받지 않습니다. 끄면 더 이상 전송하지 않습니다.

Neeson & Sea가 보관하는 카운터. 라이선스 서비스가 세는 것은 여섯 가지 이벤트입니다. 결제 페이지 클릭, 주문 생성, 주문 결제, 코드 수령, 결제 완료 페이지 제공, 짧은 코드 교환 — 이를 날짜별로, 그리고 ?src= 캠페인 태그별로 집계합니다. 카운터에는 어떤 식별자도 담기지 않습니다. IP 주소도, 쿠키도, 기기 ID도 없으며, 개인과 연결될 수 있는 것은 없습니다. 어느 채널에 힘을 쓸 가치가 있는지 알기 위해서만 존재합니다.

남용 방지는 별개입니다. 주문 페이지, 결제 완료 페이지, 재발급 페이지에 대한 요청에는 속도 제한이 걸립니다. 속도 제한 키에는 클라이언트 IP 주소를 잘라낸 SHA-256을 사용하며, 자동으로 만료됩니다. 만료 시간은 결제 완료 페이지와 재발급 페이지가 약 15분, 활성화가 10분입니다. 재발급 시도는 그 잘라낸 해시, 주문 id를 잘라낸 해시, 결과를 담은 감사 행을 한 줄 기록합니다. 이 행은 남용을 조사할 수 있도록 최대 30일 동안 보관합니다. 속도 제한 키와 감사 행은 위의 집계 카운터에 포함되지 않습니다.

1. 수집하는 것

당신에 관한 사용 데이터는 전혀 수집하지 않습니다. 분석도, 이벤트 전송도, 크래시 리포트 업로드도, 기기 지문도, 광고 식별자도, 사용자 프로파일링도 없습니다.

라이선스가 네트워크에 연결하는 경우는 두 가지뿐입니다. 짧은 코드(LP-XXXX-XXXX-XXXX)의 1회 교환과, 최초 활성화 시 1회의 기기 등록입니다. 짧은 코드 교환에서 보내는 것은 다음 두 가지뿐입니다:

기기 등록: 활성화 코드 검증이 끝나면 앱은 이 Mac을 등록하기 위해 Neeson & Sea 서버에 한 번만 접속합니다. 업로드하는 것은 보드 식별자와 모델 식별자에서 로컬로 계산한 되돌릴 수 없는 SHA-256 다이제스트뿐입니다. 일련번호나 평문 모델 문자열은 보내지 않습니다. 이 다이제스트는 같은 Mac에서 항상 같은 값이라 5대 제한을 실제로 강제할 수 있습니다. 가명이며 익명은 아닙니다. 이후의 실행은 모두 로컬에서 검증됩니다.

  • 짧은 코드 — 결제 후 주문 페이지에 표시되는 12자리 코드.
  • 무작위로 생성된 기기 식별자 — 짧은 코드를 처음 교환할 때 로컬에서 UUID로 생성되어 macOS 키체인에 저장됩니다. 짧은 코드 교환과 로컬 라이선스 기록 연결에 쓰입니다. 하드웨어 일련번호, MAC 주소, 디스플레이 EDID, 컴퓨터 이름, Apple ID, 계정 정보는 전혀 포함되지 않습니다.

이 요청은 짧은 코드를 해당 주문의 긴 서명된 활성화 코드로 교환해 달라고 요청할 뿐입니다. LP-로 시작하는 코드(긴 서명 코드)는 앱에 내장된 공개 키로 완전히 오프라인에서 검증됩니다. 최초 활성화 때는 위에서 설명한 대로 이 Mac의 등록도 한 번 이루어지며, 이후 실행은 모두 로컬에서 검증됩니다. 무작위 식별자로 기기 모델을 역추적할 수는 없습니다.

현재 상태: 결제는 이용 가능합니다. 결제는 Neeson & Sea가 직접 운영하는 결제 페이지와 라이선스 서비스를 통한 암호화폐입니다. LP- 활성화 코드는 오프라인으로 검증됩니다. 라이선스 네트워크를 쓰는 것은 두 가지뿐입니다. 짧은 코드 교환과, 최초 활성화 시의 기기 등록입니다. 둘 다 Neeson & Sea 서비스로만 가며 제3자에게는 가지 않습니다.

2. 수집하지 않는 것

다음은 앱이 사용하되 사용자의 Mac 메모리 안에서만 처리하고 절대 업로드하지 않는 항목입니다.

  • 디스플레이 모델, 벤더 ID, 제품 ID, EDID 전문과 물리 색역.
  • 해상도, 주사율, 현재 감마 테이블, 밝기와 색온도 값.
  • 디스크 용량, 캐시 디렉터리 크기, 스캔 결과와 정리 기록.
  • 창 제목과 위치(창 배치와 세션 복원에 필요하며, 손쉬운 사용 권한을 허용한 뒤에만 읽을 수 있습니다).
  • 휠 이벤트와 단축키 키 입력(스크롤 스무딩과 마우스 매핑에 필요).

그리고 다음은 아예 건드리지 않습니다.

  • 디스플레이 모델, EDID, 일련번호를 업로드하지 않습니다 — 그런 코드 경로 자체가 없습니다.
  • 사용 시간, 기능 클릭 횟수, 실행 횟수를 업로드하지 않습니다.
  • 키보드 입력을 기록하지 않습니다. 스크롤 스무딩이 읽는 것은 휠 이벤트의 이동량뿐입니다. 키보드는 '⌘를 누르는 동안 스무딩을 우회한다'는 한 가지 상태 판정에만 씁니다.
  • 마이크, 화면 기록, 전체 디스크 접근 권한을 요청하지 않습니다. 저장 공간 스캔은 읽기 전용이며, 시스템이 보호하는 디렉터리는 macOS 규칙대로 건너뜁니다.
  • 화면과 소리를 캡처하지 않습니다. 앱에 카메라나 마이크 호출이 없습니다. (Info.plist에는 NS*UsageDescription 키가 전혀 없습니다.)

3. 네트워크에 연결하는 것은 세 가지뿐

아래 세 가지를 제외하면 앱은 능동적인 네트워크 요청을 보내지 않습니다. 모두 HTTPS이며 평문 HTTP는 쓰지 않습니다.

1. 업데이트 확인

앱은 appcast.xml에 버전 목록을 한 번 요청해 새 버전이 있는지 판단합니다. 이 목록은 이 웹사이트와 함께 GitHub Pages에서 호스팅됩니다. 이 요청에는 라이선스 키도, 기기 식별자도, 사용 데이터도 없습니다. 또한 기본적으로 꺼져 있습니다: '일반' 패널에서 자동 확인을 직접 켰거나(이후 하루 최대 한 번), '업데이트 확인'을 직접 눌렀을 때만 전송됩니다.

호스트인 GitHub는 여느 웹 서버와 마찬가지로 IP 주소, 요청 시각, 클라이언트 식별자를 보게 됩니다. 이는 호스팅 서비스의 일상적인 접근 로그이며, Neeson & Sea가 추가로 수집하는 것이 아닙니다.

2. 라이선스 확인

이것은 활성화할 때만 발생합니다. 긴 서명 코드(LP-…)는 앱에 내장된 공개 키로 로컬에서 오프라인으로 검증되며, 이 검증은 요청을 보내지 않습니다. 짧은 코드(LP-XXXX-XXXX-XXXX)는 교환할 때 Neeson & Sea 라이선스 서비스와 한 번만 통신합니다:

  • 짧은 코드 교환: 짧은 코드와 위에 설명한 무작위 기기 식별자를 보내고 긴 서명 코드를 받습니다.
  • 이 Mac 등록: 최초 활성화 시 코드와 로컬에서 계산한 기기 다이제스트를 한 번 보내, 긴 코드를 5대의 Mac으로 제한할 수 있게 합니다. 같은 코드를 같은 Mac에서 쓰면 인식되어 두 번째 슬롯을 차지하지 않습니다.
  • 긴 서명 코드: 내장 공개 키로 오프라인 검증합니다. 계정 없음, 서버 없음, 주기적 통신 없음. 오프라인이었다는 이유로 만료되지 않습니다.

Neeson & Sea는 이를 의도적으로 오프라인 우선으로 만들었습니다. 재확인 실패, 연결 끊김, 서버 장애는 라이선스 상태를 바꾸지 않고 오류 한 줄만 기록합니다. 오랫동안 연결되지 않아도 7일의 유예 기간 동안 평소처럼 쓸 수 있습니다. 활성화하기 전에는 라이선스 요청이 전혀 전송되지 않고, 계정을 입력할 필요도 없습니다.

현재 상태: 이 단계는 적용됩니다. 긴 LP- 코드는 오프라인으로 검증됩니다. 라이선스 요청은 최초 활성화 시의 1회 기기 등록과, 사용하는 경우 위의 짧은 코드 교환뿐입니다. 둘 다 Neeson & Sea 서비스로 갑니다. 활성화하기 전에는 앱이 라이선스 요청을 전혀 보내지 않고 계정도 요구하지 않습니다.

3. 구매 페이지나 웹사이트 열기

'구매' 또는 '웹사이트 방문'을 클릭하면 기본 브라우저에서 열립니다. 결제는 앱이 아니라 브라우저에서 이루어집니다. 구매 입구는 Neeson & Sea 서비스가 제공하는 주문 페이지이며, 기존 브라우저를 사용하고 아무것도 설치하지 않습니다.

4. 데이터가 저장되는 곳

  • 라이선스 기록(라이선스 키, 인스턴스 ID, 활성화와 재확인 시각): macOS 키체인, 서비스 이름 com.neeson.lumepane.license. 평문 plist가 아닙니다.
  • 앱 설정(체험 시작일, 인터페이스 환경설정, 단축키 지정, 자동화 규칙, 눈 보호 일정): ~/Library/Preferences/com.neeson.lumepane.plist.
  • 정리 격리 영역과 작업 기록: ~/Library/Application Support/com.neeson.lumepane/Clean/. 정리 대상 파일은 먼저 이곳 격리 영역으로 옮겨지고, 언제든 복원할 수 있습니다. 영구 삭제를 선택할 수 있게 되는 것은 30일이 지난 뒤입니다.
  • 시스템 권한: 손쉬운 사용 권한은 macOS가 관리하며 '시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용'에서 언제든 취소할 수 있습니다.

완전히 지우려면: 앱을 종료한 뒤 위의 두 디렉터리/파일을 삭제합니다. 더 확실하게 하려면 키체인 접근에서 그 항목 하나도 지우십시오. 앱은 백그라운드 서비스나 데몬을 설치하지 않으며, 삭제 후에도 상주 구성 요소를 남기지 않습니다.

5. 제3자

  • Neeson & Sea 라이선스 서비스(Cloudflare Workers): 주문 페이지 제공, 결제와 온체인 기록 대조, 라이선스 코드 발급, 짧은 코드 교환을 처리합니다. 주문 번호, 온체인 트랜잭션 해시와 금액, 그리고 경로에 따라 무작위 기기 식별자(짧은 코드 교환) 또는 1회성 기기 다이제스트(활성화)를 봅니다. 이름이나 계정은 보지 않으며, 프로필도 만들지 않습니다. 이메일 주소를 수집하는 채널로 구매했거나 코드 재발급 양식을 사용한 경우에는 그 주소도 처리합니다. 코드를 다시 보낼 수 있도록 주문 기록과 함께 저장하고(재발급이 계속 동작하도록 주문 기록을 보관합니다), 잘라낸 SHA-256 해시를 저장해 서명된 코드에 넣습니다. 이렇게 하면 원본 주소를 대조하지 않고도 주문을 찾을 수 있습니다.
  • 공개 블록체인 API(예: TronGrid 및 공개 RPC): 송금 확인을 위해 공개 체인 데이터를 읽습니다. 개인 데이터는 전송하지 않습니다.
  • GitHub: 이 웹사이트, 업데이트 매니페스트, 다운로드를 호스팅합니다. 호스트로서 일반 접속 로그(IP, 시각, 경로)를 보관합니다.

이 외에 이 앱과 이 사이트에는 분석 서비스, 광고 네트워크, 소셜 플러그인, 서드파티 글꼴이 없습니다.

6. 아동

LumePane은 Mac 사용자를 위한 데스크톱 도구입니다. 아동을 대상으로 설계되지 않았고, 아동의 정보를 의도적으로 수집하지 않습니다.

7. 방침 변경

향후 버전에서 네트워크 동작이 바뀌면(예: 클라우드 동기화 추가) 이 방침을 먼저 갱신하고 변경 사항을 변경 기록에 적습니다. '계속 사용하면 동의한 것으로 본다'는 문구로 수집 범위를 조용히 넓히지 않습니다.

8. 문의

이 방침에 대한 질문이 있거나 보관 중인 라이선스 정보를 확인하려면 GitHub에서 이슈를 열어 주세요.
