Frequently asked questions

1. Why does my display say “DDC not responding”?

Because that panel doesn't implement DDC/CI (the display control command set). This is not a problem with the app: some displays, TVs, docks, and adapters simply don't respond to these commands, and the UP32R7-A used for testing by Neeson & Sea is one of them.

When that happens, hardware brightness, hardware volume, and input switching are unavailable. The app clearly reports “DDC not responding” and automatically hands brightness to software dimming (darkening the image through the CoreGraphics gamma table). Software dimming still darkens the screen, but it doesn't change the panel's backlight current, so power savings differ from hardware dimming.

Full diagnosis, including which of the five causes is the monitor's fault and which is the cable's: DDC/CI not responding on macOS.

2. What if smooth scrolling conflicts with Mos or Mac Mouse Fix?

Tools like these all smooth scrolling by intercepting scroll-wheel events, and running two at once means each swallows the other's wheel input. The app detects similar tools at launch and while running, and warns about the conflict. To resolve it, pick one:

  • keep only one smoothing tool;
  • turn off scroll smoothing in this app's Scrolling panel, or turn off the other tool;
  • keep both and use safe mode: holding ⌘ while scrolling temporarily hands control back to the system, and windows that treat the wheel as a zoom control (image viewers, slide decks, maps) are handed back automatically.

3. How do I restore my display's original state?

From lightest to heaviest, work through these in order:

  1. In-app restore: Display panel, at the bottom → “Restore this display” or “Hand back to system calibration”. Both are also in the menu bar icon's menu.
  2. Without the app: in Terminal, run bash Scripts/restore-dimming.sh. It writes brightness, color temperature, and presets back to neutral values and does not need the app to be running.
  3. Stuck display arrangement / external display not detected: this needs an administrator password. Delete the system-level display configuration and restart: 
    sudo rm /Library/Preferences/com.apple.windowserver.displays.plist
rm -f ~/Library/Preferences/ByHost/com.apple.windowserver.displays.*.plist
sudo shutdown -r now
    Deleting only the user-level file is not enough — the display arrangement actually lives in the system-level file, and you must restart afterwards.
  4. If you can't get into the system at all: power off → hold the power button → Options → Terminal, and run emergency-restore-display.sh (in the Scripts folder of the installation directory).

These recovery paths are deliberately built not to depend on the app. Neeson & Sea has managed to black out a display during testing, so “you can always recover” is a hard product requirement, not a bonus feature.

4. What still works after the trial ends?

During the 14-day trial, every feature is available. After the trial ends, only 5 enhancement features pause: scroll smoothing, mouse button mapping, eye-care scheduling, automation rules, and session save/restore.

Recovery operations always remain available and never depend on a network connection: restore this display, hand back to system calibration, display sleep, quit, the license page, the About page, and the uninstall/reset entry point. In other words, an expired trial will never lock you in front of a screen you can't restore.

6. Can cleanup delete the wrong thing?

The design goal is to make “deleted the wrong thing” as unlikely as possible:

Which groups are actually safe to delete, with their exact paths and what rebuilding costs: cleaning macOS developer caches without losing anything.

  • it only handles 13 categories of artifacts with a deterministic rebuild path (Xcode DerivedData, SwiftPM, CocoaPods, npm/pnpm/Yarn, Go, Gradle, __pycache__, Rust target, crash reports, Homebrew caches, and so on);
  • never part of cleanup: Documents, Desktop, Downloads, Pictures, Movies, Music, preferences, Application Support, the Keychain, Mail, Messages, Safari;
  • before deleting, files are moved into quarantine first, kept for 30 days by default, and restorable at any time;
  • permanent deletion is off by default: exactly one function in the whole app can permanently delete, and it requires six conditions to hold at once — fail any one and it aborts;
  • automation rules can pre-scan, never delete.

7. Do you collect information about me automatically?

No. By default the app has no telemetry, no third-party analytics, and does not upload usage data or crash logs automatically. The only exception is an optional anonymous usage pulse, off by default; if you enable it, it sends a random installation ID, version and trial/licensed state at most once a day, with no IP, account, display or activity data. What “Report a Problem” generates stays on your Mac and must be copied or sent by you by hand. By default only three things reach the network: checking for updates (off by default), verifying a license, and opening a web page when you click it yourself. The optional pulse is a fourth only if you turn it on. See the Privacy Policy for details.

How to report a problem

  1. Open General → About → Report a Problem and click to generate diagnostic information;
  2. read it through yourself (it removes serial numbers, user names, file paths, and license keys, but you should still check);
  3. click “Copy to Clipboard”, then open a new issue on GitHub and paste it in along with a description of the problem.

Attaching a crash log (if the app has crashed)

  1. open Applications → Utilities → Console;
  2. select “Crash Reports” in the left sidebar;
  3. find the LumePane entry, right-click → Reveal in Finder;
  4. drag the .ips file from the relevant time into that issue as an attachment.

The usual location for logs is ~/Library/Logs/DiagnosticReports/.

What LumePane cannot do

  • LumePane cannot provide hardware brightness, volume, or input switching on a display that doesn't support DDC/CI;
  • LumePane cannot guarantee that software dimming looks identical to hardware dimming;
  • LumePane cannot operate macOS display arrangement for you — recovery has to follow the steps above;
  • LumePane cannot reverse a cryptocurrency payment on-chain. If the Software doesn't work for you and LumePane cannot fix it, contact Neeson & Sea within 14 days of purchase and Neeson & Sea will refund you in the same currency (see the license for the full refund policy).
