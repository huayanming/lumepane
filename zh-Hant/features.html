6.0 新增

顯示面板現在讀取真實的 HDR/EDR 狀態、旋轉角與目前 ICC 設定；面板支援時提供硬體色溫（VCP 0x0C）滑桿。工具面板新增記憶體剪貼簿歷史與截圖卡。音訊面板顯示每個輸出裝置的取樣率；滑鼠面板新增鍵盤重複設定與觸控板唯讀狀態；視窗面板可隱藏其他應用。 7.1.0 新增夜覽唯讀狀態卡與專注權限說明。

命令列

二進位裡帶著與面板相同的控件，外加自我檢測。適合寫腳本，也適合核對應用程式自己的說法。

參數作用
--list / --list-modes列出線上顯示器與全部模式，包括 macOS 隱藏的 HiDPI 模式。
--set-brightness / --offset-brightness / --set-temperature設定軟體調光、相對增減，或設定色溫（2700–9000 K）。
--preset / --set-resolution / --reset套用場景預設、切換解析度（優先 HiDPI），或把校正交回 ColorSync。
--dump-gamma列印目前伽馬表的中點值。唯讀。
--login-item / --request-accessibility讀取或設定登入時啟動；請求輔助使用權限。
--scroll-report / --scroll-selftest即時捲動診斷；驗證插值演算法與總量守恆。
--license-selftest / --cli-selftest授權狀態機與降級邊界；參數模糊測試、去識別化與開源聲明。
--switch-probe / --switch-selftest唯讀的開關可用性與狀態；讀—切換—讀自我檢測。
--probe / --full / --language / --help診斷、完整輸出、介面語言、說明。

明確不做的事

  • 深色模式、勿擾模式、夜覽、原彩顯示、隱藏桌面：需要系統私有介面，公開 API 做不到。
  • 一鍵清 Xcode 快取，或從選單列切換解析度：前者會真的刪資料，後者可能讓螢幕黑掉。
  • 鎖鍵盤：可能讓鍵盤失去回應，所以不做成一鍵動作。
  • 沒有遙測、沒有埋點、沒有帳號系統。

隱私邊界

驗簽完全離線：長 LP- 碼用應用程式內建的公鑰做 Ed25519 驗證。應用程式唯一用到網路的地方是啟用——領取短碼，以及把裝置登記一次，都發往尼森與海自己的發碼服務，長 LP- 碼因此才能限制在 5 台 Mac 上。這次登記攜帶一個不可逆的 SHA-256 摘要，在本機由主機板識別碼與機型識別碼算出（sha256(IOPlatformUUID + 機型號)）；不會傳送序號、明文機型字串、MAC 位址、顯示器 EDID、使用者名稱或帳號。之後每次啟動都在本機驗簽。更新檢查由 Sparkle（MIT）完成，預設關閉，除非你主動開啟。匯出的診斷報告在離開應用程式前會去掉序號、授權碼、絕對路徑與使用者名稱。

這一頁的說法都可供核對。上面的自我檢測指令是二進位的一部分，透明度頁列出每一項斷言什麼。
