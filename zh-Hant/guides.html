Mac 外接顯示器的各種毛病

這些頁面一頁只講一個問題，用的就是你會搜的那些說法。每一頁先講機制，再講怎麼做——包括「答案不是尼森與海的應用程式」這種時候。

顯示器不聽你的

  • 亮度鍵在外接顯示器上沒反應 — DDC/CI 不回應：為什麼多數時候問題在面板、線材或介面，以及按什麼順序排查。
  • 休眠之後亮度又被重置 — 調暗、闔蓋、回來又亮了。到底是什麼時候丟掉的，以及怎麼留住它。
  • 外接顯示器的亮度怎麼調？ — 三種辦法，按值得嘗試的順序，以及三種都不行時怎麼辦。

看起來不對

  • 文字發虛、發軟 — 同一個解析度往往存在兩份——一份做了 HiDPI 縮放，一份是 1:1 原生。怎麼分辨它們。
  • 色彩發灰、發平 — 兩種抱怨，一個解釋：調暗會怎樣影響你設好的顏色，以及怎麼調回來。
  • 按時段調暗，最後把螢幕調成了全黑 — 會越乘越小的倍數、你拖滑桿時停跳的心跳，以及為什麼「幂等」是全部的關鍵。

手感不對

  • 滑鼠滾輪一格一格地跳 — macOS 交給滾輪的是離散的格，交給觸控板的是連續手勢。修好它的機制，以及路上的三個坑。
  • 滑鼠加速關不掉、關不住 — 流傳的做法只動了兩層裡的一層。附實測數值，以及那個並不存在的 API 名。

打掃乾淨，但不弄丟東西

  • 清理快取而不弄丟東西 — 那幾十 GB 到底在哪裡，以及讓清理「可回復」的那一條規則。

怎麼選工具，以及怎麼驗證尼森與海

  • Mac 外接顯示器工具該用哪個？ — 這一領域四款應用的誠實對比，包括尼森與海什麼時候是錯誤的選擇。
  • 自己驗證 — 尼森與海是新應用、沒有評測。這裡講怎麼在信任之前，先核對下載、簽章與付款。
  • 尼森與海怎麼審查自己的產品 — 本站結論背後的測量，以及尼森與海沒有做的那些說法。

深入一點的五篇

  • 兩個 App 搶同一個設定 — 為什麼亮度會自己變；按 bundle-id 前綴辨識對手；寧可漏報也不誤報。
  • 是不是這次更新的鍋 — 方向就是證據；「正常」必須是明確的正面確認；只讀凍結的快照。
  • 怎麼真正測一台顯示器 — 五個全螢幕測試；為什麼測試工具絕不能把你困住。
  • 伽馬表到底做了什麼 — 五步運算、繞 0.5 旋轉的對比，以及三個陷阱。
  • 哪一層在把螢幕調暗 — 硬體 / 軟體 / 不可用 / 未知，以及為什麼後兩者不一樣。
