6.0 の新機能

ディスプレイパネルは HDR/EDR の実状態、回転角、現在の ICC プロファイルを表示し、対応パネルではハードウェア色温度（VCP 0x0C）のスライダーを出します。ツールパネルにはメモリ内のクリップボード履歴とスクリーンショットカードを追加。オーディオは各出力のサンプルレート、マウスはキーリピート設定とトラックパッドの読み取り専用状態、ウインドウは他のアプリを隠す操作を追加しました。 7.1.0 では Night Shift の読み取り専用カードと集中モードの権限説明を追加しました。

コマンドライン

バイナリには、パネルと同じコントロールとセルフテストが入っています。スクリプトからも、アプリ自身の主張を確かめるのにも使えます。

フラグ内容
--list / --list-modesオンラインのディスプレイと全モード（macOS が隠している HiDPI モードを含む）を一覧します。
--set-brightness / --offset-brightness / --set-temperatureソフトウェア調光を設定し、相対的に増減し、色温度（2700–9000 K）を設定します。
--preset / --set-resolution / --resetシーンプリセットを適用し、解像度を切り替え（HiDPI 優先）、キャリブレーションを ColorSync に返します。
--dump-gamma現在のガンマテーブルの中点を出力します。読み取り専用です。
--login-item / --request-accessibilityログイン時の起動を読み取り・設定します。アクセシビリティ権限を要求します。
--scroll-report / --scroll-selftestリアルタイムのスクロール診断。補間アルゴリズムと総量の保存を検証します。
--license-selftest / --cli-selftestライセンス状態機械と縮退の境界。引数のファジング、伏字処理、オープンソース表記。
--switch-probe / --switch-selftest読み取り専用のスイッチ可用性と状態。読み取り→切り替え→読み取りのセルフテスト。
--probe / --full / --language / --help診断、完全な出力、インターフェイス言語、ヘルプ。

意図的にやらないこと

  • ダークモード、おやすみモード、Night Shift、True Tone、デスクトップを隠す：システムの非公開インターフェイスが必要で、公開 API ではきれいに実現できません。
  • Xcode キャッシュのワンクリック削除、メニューバーからの解像度切り替え：前者は本当にデータを消し、後者は画面が真っ暗になることがあります。
  • キーボードのロック：キーボードが反応しなくなることがあるため、ワンクリックのアクションにはしていません。
  • テレメトリーも、解析も、アカウント システムもありません。

プライバシーの境界

検証は完全にオフラインです。長い LP- コードは、アプリに内蔵された公開鍵で Ed25519 検証します。アプリがネットワークを使うのはアクティベーション時だけ — 短いコードの引き換えと、デバイスの 1 回だけの登録で、宛先は当方のライセンス サービスです。長い LP- コードを 5 台の Mac までに制限できるのはこのためです。この登録で送るのは、ボード識別子（IOPlatformUUID）とモデル識別子からローカルで計算した不可逆な SHA-256 ダイジェストだけです。シリアル番号、平文のモデル名、MAC アドレス、ディスプレイの EDID、ユーザー名、アカウントは送りません。以降の起動はすべてローカルで検証され、アップデート確認は Sparkle（MIT）が行い、既定ではオフです。書き出した診断レポートは、アプリの外に出る前にシリアル番号、ライセンス コード、絶対パス、ユーザー名を伏せます。

このページの主張は、確かめられるように書いています。上のセルフテスト コマンドはバイナリの一部で、透明性ページに各コマンドが何を検証するかが並んでいます。
