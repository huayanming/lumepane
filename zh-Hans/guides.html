Mac 外接显示器的各种毛病

这些页面一页只讲一个问题，用的就是你会搜的那些说法。每一页先讲机制，再讲怎么做——包括「答案不是尼森与海的应用」这种时候。

显示器不听你的

  • 亮度键在外接显示器上没反应 — DDC/CI 不应答：为什么多数时候问题在面板、线材或接口，以及按什么顺序排查。
  • 休眠之后亮度又被重置 — 调暗、合盖、回来又亮了。到底是什么时候丢掉的，以及怎么留住它。
  • 外接显示器的亮度怎么调？ — 三种办法，按值得尝试的顺序，以及三种都不行时怎么办。

看起来不对

  • 文字发虚、发软 — 同一个分辨率往往存在两份——一份做了 HiDPI 缩放，一份是 1:1 原生。怎么分辨它们。
  • 色彩发灰、发平 — 两种抱怨，一个解释：调暗会怎样影响你设好的颜色，以及怎么调回来。
  • 按时段调暗，最后把屏幕调成了全黑 — 会越乘越小的倍数、你拖滑杆时停跳的心跳，以及为什么「幂等」是全部的关键。

手感不对

  • 鼠标滚轮一格一格地跳 — macOS 交给滚轮的是离散的格，交给触控板的是连续手势。修好它的机制，以及路上的三个坑。
  • 鼠标加速关不掉、关不住 — 流传的做法只动了两层里的一层。附实测数值，以及那个并不存在的 API 名。

打扫干净，但不弄丢东西

  • 清理缓存而不丢东西 — 那几十 GB 到底在哪里，以及让清理「可回退」的那一条规则。

怎么选工具，以及怎么验证尼森与海

  • Mac 外接显示器工具该用哪个？ — 这一领域四款应用的诚实对比，包括尼森与海什么时候是错误的选择。
  • 自己验证 — 尼森与海是新应用、没有评测。这里讲怎么在信任之前，先核对下载、签名与付款。
  • 尼森与海怎么审查自己的产品 — 本站结论背后的测量，以及尼森与海没有做的那些说法。

深入一点的六篇

这六篇是最近写的，每一篇都对着源码写，不靠印象。

  • 两个 App 抢同一个设置
    为什么亮度会自己变；按 bundle-id 前缀识别对手；宁可漏报也不误报。
  • 是不是这次更新的锅
    方向就是证据；「正常」必须是明确的正面确认；只读冻结的快照。
  • 怎么真正测一台显示器
    五个全屏测试；为什么测试工具绝不能把你困住。
  • 伽马表到底做了什么
    五步运算、绕 0.5 旋转的对比度，以及三个陷阱。
  • 哪一层在把屏幕调暗
    硬件 / 软件 / 不可用 / 未知，以及为什么后两者不一样。
    • 地址、EDID 的浅层限制、那一拍、以及为什么必须用 dlsym。
