显示面板现在读取真实的 HDR/EDR 状态、旋转角与当前 ICC 配置；面板支持时提供硬件色温（VCP 0x0C）滑块。工具面板新增内存剪贴板历史与截图卡。音频面板显示每个输出设备的采样率；鼠标面板新增键盘重复设置与触控板只读状态；窗口面板可隐藏其他应用。 7.1.0 新增夜览只读状态卡与专注权限说明。

命令行

二进制里带着与面板相同的控件，外加自检。适合写脚本，也适合核对应用自己的说法。

参数作用
--list / --list-modes列出在线显示器与全部模式，包括 macOS 隐藏的 HiDPI 模式。
--set-brightness / --offset-brightness / --set-temperature设置软件调光、相对增减，或设置色温（2700–9000 K）。
--preset / --set-resolution / --reset应用场景预设、切换分辨率（优先 HiDPI），或把校准交回 ColorSync。
--dump-gamma打印当前伽马表的中点值。只读。
--login-item / --request-accessibility读取或设置登录时启动；请求辅助功能权限。
--scroll-report / --scroll-selftest实时滚动诊断；验证插值算法与总量守恒。
--license-selftest / --cli-selftest许可状态机与降级边界；参数模糊测试、脱敏与开源声明。
--switch-probe / --switch-selftest只读的开关可用性与状态；读—切换—读自检。
--probe / --full / --language / --help诊断、完整输出、界面语言、帮助。

明确不做的事

  • 深色模式、勿扰模式、夜览、原彩显示、隐藏桌面：需要系统私有接口，公开 API 做不到。
  • 一键清 Xcode 缓存，或从菜单栏切换分辨率：前者会真的删数据，后者可能让屏幕黑掉。
  • 锁键盘：可能让键盘失去响应，所以不做成一键动作。
  • 默认没有遥测、不接第三方埋点、没有账号系统。唯一的匿名使用统计是可选项，默认关闭。

隐私边界

验签完全离线：长 LP- 码用应用内置的公钥做 Ed25519 校验。应用唯一用到网络的地方是激活——领取短码，以及把设备登记一次，都发往尼森与海自己的发码服务，长 LP- 码因此才能限制在 5 台 Mac 上。这次登记携带一个不可逆的 SHA-256 摘要，在本地由主板标识和机型标识算出（sha256(IOPlatformUUID + 机型号)）；不会发送序列号、明文机型字符串、MAC 地址、显示器 EDID、用户名或账号。之后每次启动都在本地验签。更新检查由 Sparkle（MIT）完成，默认关闭，除非你主动开启。导出的诊断报告在离开应用前会去掉序列号、许可码、绝对路径和用户名。

这一页的说法都可供核对。上面的自检命令是二进制的一部分，透明度页列出每一项断言什么。
