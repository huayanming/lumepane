New in 6.0

Display now reports HDR/EDR capability, rotation and the active ICC profile, and exposes the monitor's hardware color temperature (VCP 0x0C) when the panel supports it. Tools gains an in-memory clipboard history and a screenshot card. The audio panel shows each output's sample rate; the mouse panel adds keyboard repeat settings and read-only trackpad status; the window panel can hide other apps. 7.1.0 adds a read-only Night Shift status card and a clear Focus permission note.

The binary carries the same controls as the panel, plus the self-tests. Useful for scripts, and for checking the app's own claims.

What the app deliberately does not do

  • Dark mode, Do Not Disturb, Night Shift, True Tone and hiding the desktop: they need private system interfaces, and the public APIs cannot do it cleanly.
  • One-click Xcode cache deletion, or resolution switching from the menu bar: one can really delete data, the other can blank the screen.
  • Keyboard lock: it can leave the keyboard unresponsive, so it is not a one-click action.
  • No telemetry by default, no third-party analytics, no account system. One optional anonymous usage pulse is off by default.

Privacy boundary

Verification is fully offline: a long LP- code is checked against a public key inside the app with Ed25519. Apart from the opt-in anonymous pulse, the app's only network use is activation — redeeming a short code and registering the device once, with Neeson & Sea's own licensing service, so a long LP- code can be limited to 5 Macs. That registration carries an irreversible SHA-256 digest, computed locally from the board identifier and the model identifier; no serial number, plaintext model string, MAC address, display EDID, user name or account is sent. After that, every launch is verified locally, and update checks stay off unless you enable them. Exported diagnostic reports are redacted for serial numbers, licence codes, absolute paths and user names before they leave the app.

The claims on this page are meant to be checkable. The self-test commands above are part of the binary, and the transparency page lists what each one asserts.
