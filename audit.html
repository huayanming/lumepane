How Neeson & Sea check ourselves

Every claim on this site is checked by an automated script that reads the source of truth. A failing check blocks the build.

18 automated checks

  • check-app-claims — app-side negative promises: the network allowlist, the permanent-delete allowlist, zero telemetry, updates off by default, and permission wording.
  • check-brand-naming — the shipped app, executable and DMG use the LumePane name; a legacy LumePane artifact name fails the gate.
  • check-audit-report — the audit report matches the docs, and its guard counts equal the measured ones.
  • check-channel-tags — campaign tags referenced in docs must actually exist.
  • check-conventions — naming and structure conventions, the per-file line cap, and Chinese literals must be localised.
  • check-eula — EULA in eight languages: structure, feature references, English prevails.
  • check-guard-coverage — every guard has a recorded proof.
  • check-launch-posts — numbers in launch posts match code facts.
  • check-localization — seven locales: same keys, same format specifiers, same quoted strings.
  • check-pricing — the price is stated the same way everywhere.
  • check-privacy — the privacy statement matches actual data behaviour.
  • check-shell-scripts — strict mode and dangerous-command safeguards in shell scripts.
  • check-site-claims — every number on the site equals the code fact.
  • check-site-links — internal links, anchors and hreflang all resolve.
  • check-site-seo — title, description, canonical and sitemap are complete.
  • check-typos — common misspellings and punctuation in English pages.
  • check-versions — the version is the same on the site, in the update feed and in the download filename.
