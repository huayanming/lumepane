Please read this section. The Software is not “absolutely safe”: it genuinely changes the state of your display and performs file cleanup operations.

1. Provided as is

2. What the Software does

With the authorization of your operating system, the Software can:

  • adjust software dimming, contrast, gamma, and color temperature, and (where the display supports it) DDC/CI hardware brightness, contrast, volume, and input source;
  • switch resolution and refresh rate;
  • write display parameters into the GPU gamma table;
  • scan caches, derived data, and rebuildable artifacts produced by the system and third-party apps, move them into quarantine, and permanently delete them once the conditions are met.

3. Adjusting display parameters is your responsibility

Dimming, color changes, and switching resolution, refresh rate, or input source all change the current state of your screen. Extreme settings, or settings that are outdated or incompatible with your display's firmware, may cause image corruption, a black screen, a lost input signal, or an abnormal display arrangement (monitor position or main display). Please make sure you understand the consequences before using these features; you bear the resulting consequences yourself. Neeson & Sea recommendss against trying aggressive settings when you have only one display path, no way to operate the machine remotely, or work in progress that cannot be interrupted.

4. What Neeson & Sea does not guarantee

  • Neeson & Sea does not guarantee that every display supports DDC/CI. Some panels — including the UP32R7-A used for testing on this project — do not implement DDC/CI at all, in which case hardware dimming, volume, and input switching are unavailable. The Software clearly reports “DDC not responding” and falls back to the software channel instead of pretending to succeed.
  • Neeson & Sea does not guarantee that software dimming looks identical to hardware dimming. Software dimming darkens the image through the gamma table and does not change the panel's backlight current, so power savings, minimum brightness, and contrast behavior can all differ.
  • Neeson & Sea does not guarantee that color temperature, gamma, and color match a professional colorimeter or the factory calibration. The Software converts values against the curve read when the app first takes over; that is a perceptual adjustment, not metrology-grade calibration.
  • Neeson & Sea does not guarantee that behavior stays the same after a macOS update, a GPU driver update, or a display firmware update.
  • Neeson & Sea does not guarantee that cleanup finds every rebuildable artifact on your machine. The feature is deliberately small: it handles only categories with a deterministic rebuild path, preferring to clean too little over deleting something by mistake.
  • Neeson & Sea does not guarantee that the recovery paths work with every combination of third-party hardware, cable, and system configuration.
